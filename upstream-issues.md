# Upstream issue triage — limo-app/limo

Triage of every **open** issue on the upstream repository [`limo-app/limo`](https://github.com/limo-app/limo/issues) (159 open at time of writing), mapped against this fork's existing issue list.

- **Tracked (new fork issue):** valid upstream issues with no existing fork coverage — a fork issue was created and links back to the original. Multiple duplicate upstream reports of the same problem were consolidated into one fork issue.
- **Not actionable (no fork issue):** thank-you/meta posts, pure support/configuration questions, environment-specific reports with no identifiable defect, or items already implemented.
- **Already covered:** the topic is already represented by an existing fork issue (see the appendix table); omitted from the main list.
